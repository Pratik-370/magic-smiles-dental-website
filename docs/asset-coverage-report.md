## 3. Manual Review Flags Before Production Launch

1. **GoDaddy-Bundled Getty Images (28 assets):** All `isteam/getty/*` images were licensed under GoDaddy's Website Builder CDN integration. When migrating off GoDaddy to a standalone React deployment, confirm with the clinic owner whether they hold standalone Getty licenses or wish to keep/replace any stock images (client-owned clinic photos in `fun-zone-gallery/` are completely safe to reuse).
2. **Concept Pitch Slides (`Picsart_25-10-11_*`, 5 assets):** `story-03-billy-and-moe.jpg` and `story-04-gummy-the-gum-goblin.jpg` contain `"COMPARABLES"` callouts showing small thumbnails of third-party copyrighted characters (*Dora the Explorer*, *Swiper*, *Spike*, etc.), and `story-02` contains moodboard images. Recommend confirming with the client whether to render these 5 images verbatim, crop/exclude the `"COMPARABLES"` callouts, or convert their story text + character art into clean native React cards.
3. **DOC Mobile Bus Crop (`mobile-dental-outreach-bus.jpg`):** The raw asset is a `943x2048` iPhone screenshot with iOS status/action bars at top and bottom. Preserve the original file in `public/assets/`, and apply clean CSS `object-fit` / aspect cropping in React (matching the source site's `cr=t:33.28%,h:23.02%`) so the iOS UI never appears in the UI.
